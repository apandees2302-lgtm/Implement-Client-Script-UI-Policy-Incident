# Implement Client Script & UI Policy (Incident)

## Project Title
Implement Client Script & UI Policy (Incident)

## Platform
ServiceNow

## Module
Incident Management

## Objective
To improve data accuracy and consistency in Incident records by using UI Policies and Client Scripts.

## Key Features
- High Impact Control using UI Policy
- Urgency auto-update using onChange Client Script
- Assigned To validation using onSubmit Client Script
- State list-edit restriction using onCellEdit Client Script

- ServiceNow
- JavaScript
- UI Policy
- Client Scripts
- Incident Management
