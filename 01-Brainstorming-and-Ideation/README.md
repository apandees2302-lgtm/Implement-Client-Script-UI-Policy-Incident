# Phase 1 – Brainstorming & Ideation

## Project Title

Implement Client Script & UI Policy (Incident)

## Platform

ServiceNow

## Module

Incident Management

## Problem Identification

Incident records require accurate and complete information for effective incident management.

Manual data entry can result in incomplete or incorrect information. This can affect incident routing, reporting, SLA compliance, and service quality.

## Proposed Solution

The project uses ServiceNow UI Policies and Client Scripts to control Incident form behavior and validate user input.

## Proposed Features

- Control fields based on Incident Impact
- Automatically set Urgency for High Impact incidents
- Validate Assigned To before saving
- Prevent State changes through list editing
- Improve Incident data consistency

## Selected Solution

The selected solution is to implement UI Policies and Client Scripts on the Incident table in ServiceNow.

## Expected Benefits

- Improved data accuracy
- Consistent Incident records
- Better user experience
- Automatic field updates
- Improved validation
- Better data integrity
